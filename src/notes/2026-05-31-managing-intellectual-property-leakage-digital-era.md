## 1. 基本資訊

這篇文章由 Rens Scheepers、Lars Mathiassen、Atif Ahmad、Rachelle Bosua 與 Richard Baskerville 發表於 2026 年的 *International Journal of Information Management*，題目是〈Managing intellectual property leakage in the digital era: An integrated process model〉，DOI 為 10.1016/j.ijinfomgt.2025.103021。文章關心的核心問題不是 IP 重不重要，而是當 IP 越來越以 digital forms 與 digital footprints 的方式存在時，組織究竟該如何動態管理其洩漏風險。

## 2. 研究問題

本文要處理的核心問題是：在數位化環境中，組織如何理解並管理 IP leakage。作者指出，既有 IP 保護觀點多偏法律保護或靜態防禦，但在 digital era，IP 不只以專利文件存在，也體現在數位產品、程式碼、流程、平台資料與跨組織互動痕跡中。因此，真正的問題已不是單次防止外洩，而是如何持續感測風險、調整防護、並把 IP strategy 與 digitalization strategy 連動起來。

## 3. 理論基礎

理論上，這篇結合 resource-based view 與 dynamic capability theory。RBV 讓作者把 IP 視為具 VRIN 特性的關鍵資源，說明它為何是競爭優勢核心。Dynamic capability theory 則用來解釋組織如何在不斷變化的威脅與合作環境中，持續感測、整合與重組 IP 相關資源。這樣的理論配置很關鍵，因為它把 IP leakage management 從被動防禦轉成一種持續的能力建構問題。

## 4. 研究架構

文章提出一個 integrated process model，由三個相互交織的循環組成。第一是 IP digitalization cycle，處理 IP 如何在數位化過程中被重新具現、暴露並需要預防。第二是 IP leakage management cycle，處理如何利用數位創新工具去監控、辨識與應對外洩。第三是 IP strategizing cycle，強調組織如何根據內外部環境變化重新配置 IP 資源與創新策略。這三個循環共同構成一個從暴露、管理到策略調整的動態架構。

## 5. 假設邏輯

這篇不是傳統假設檢驗研究，更適合寫成命題邏輯。作者首先主張 digitalization 會讓 IP 越來越以 digital IP 與 digital footprints 的形式存在，因此暴露面擴大。接著作者推論，單靠傳統法律保護或一次性安全控制已不足以處理這種風險，組織需要透過數位監控、主動防禦與事件回應來進行持續管理。最後，真正成熟的 IP leakage management 還必須上升到 strategizing 層次，也就是在保護與開放之間動態調整，甚至在特定情況下策略性揭露部分 IP 以促進 open innovation。

## 6. 方法

研究採兩階段 systematic literature review 結合案例分析。第一階段利用 NLP 與 Naive Bayes classifier 對跨學科文獻進行篩選與分類，以建立理論整合基礎。第二階段則分析多個公開 IP leakage 案例，例如大型科技企業的商業機密爭議與原始碼外洩事件，藉此發展並驗證整合流程模型。這種方法讓文章不是只停留在概念拼接，而是有具體現象支撐其模型構成。

## 7. 結果

研究指出，數位化讓 IP 同時以 digital forms 與 digital footprints 兩種方式暴露。作者進一步發現，傳統技術控制工具在面對這些新型態暴露時常不足，因此組織必須依賴三個循環的持續互動，從預防、監控、回應到策略重構，才能形成較完整的 IP leakage management。

## 8. 理論貢獻

這篇最大的理論貢獻，是把 IP management 重新放進 IS 與 dynamic capability 脈絡。第一，它指出 IP 保護不能再被視為法律部門或高層策略的單點任務，而是需要 IS 專業與數位治理深度參與。第二，它把 IP leakage 視為數位化帶來的結構性風險，而不是偶發事件。第三，它提出 integrated process model，把防護、監控與 strategizing 串成一套可持續演化的理論架構。

## 9. 實務意涵

對實務來說，這篇很有價值。企業不能只把 IP 保護理解為簽 NDA、申請專利或事後訴訟，而要把它整合進 digitalization strategy。這意味著要利用 security analytics、AI、監控工具與流程治理去持續偵測風險，也要在 open innovation 與保護之間做更細緻的策略選擇。真正成熟的作法，不只是防止外流，而是知道什麼該保、什麼可開、何時調整邊界。

## 10. 研究限制

限制主要有幾點。第一，文章以理論推導與案例歸納為主，尚缺大規模實證驗證。第二，整合模型很有啟發，但不同產業與不同 IP 類型之間的差異尚未完全展開。第三，雖然提到 AI 與數位監控工具，但未深入比較各種技術手段的具體效能。第四，open innovation 與 IP 保護之間的平衡雖被點出，但仍需要更細的情境化研究。

## 11. 對我研究的啟發

這篇對我很有用，因為它提供了一條從 digitalization -> exposure -> governance -> strategizing 的完整鏈條。我可以把它和之前讀過的 ecosystem orchestration、distributed governance、organizational learning、performative AI 文獻接起來，形成一個更完整的「知識如何被創造、保護、分享與重組」框架。尤其值得重用的是：保護與開放不是二選一，而是需要動態能力去持續重配資源與邊界。

## 12. 整體評價

我認為這篇是 backlog 裡很值得優先讀的一篇，因為它把 IP leakage 從法務議題重新定位為數位治理與組織能力議題。文章強項是概念整合成熟，也很適合拿來補我在 knowledge protection、open innovation 與 digital governance 這條線上的理論拼圖。若要挑剔，就是它目前更像理論平台而非精準測量模型；但作為後續研究的架構性支點，我認為價值很高。
